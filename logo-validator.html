Guideline reference

Large logo · primary header lockup
360 × 39 px
Use this wide version at 360px wide. Its natural height is about 39px, so it fits the 35–40px header comfortably. Keep the artwork proportional and remove any extra canvas space.
Compact logo · secondary lockup
240 × 55 px
Use this compact version at 240px wide for comparison. Its natural height is about 55px. If the header must stay within 35–40px high, reduce it to about 153–174px wide. Never stretch it.
Canvas / viewBox
Tight crop only
viewBox should match the artwork's real bounds. Avoid large artboards or page-sized canvases — they shrink the visible mark when rendered.
Format
SVG preferred
Vector keeps the logo crisp at any DPI. Raster (PNG/JPG) should be at least 2–3× the rendered size.

Final logo delivery checklist

Confirm these four items before handing the logo to the web or content team.

1. Choose the right version Use the large version for a wide primary header. Use the compact version where the available space is narrower.
2. Use the reference sizes Large preview: 360px wide and about 39px high. Compact preview: 240px wide and about 55px high.
3. Preserve the artwork Never stretch, squash, or crop the logo artwork. If the header needs 35–40px height, scale the compact version down proportionally.
4. Check the canvas Keep the SVG viewBox tight around the artwork. Remove unnecessary whitespace, then review the result in the browser before delivery.
