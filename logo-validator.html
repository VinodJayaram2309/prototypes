Guideline reference

Large / desktop header logo
300–390 × 35–40 px
Used in the main desktop navigation. Export width should not exceed ~390px or fall under ~300px.
Small / compact logo
~240 × 40 px
For mobile header, favicons-adjacent placements, or narrow containers — same height, tighter width.
Canvas / viewBox
Tight crop only
viewBox should match the artwork's real bounds. Avoid large artboards or page-sized canvases — they shrink the visible mark when rendered.
Format
SVG preferred
Vector keeps the logo crisp at any DPI. Raster (PNG/JPG) should be at least 2–3× the rendered size.

⚠ Known issues found in the current AMETEK XMC header logo

  • Raster format: HeaderLogo.png is a PNG, not an SVG — it will blur on high‑DPI / retina screens since it can't scale.
  • Intrinsic size is 159 × 26 px — below the 300–390 × 35–40 guideline and only marginally larger than the ~159×32 render size used in Header.tsx, leaving no headroom for sharp @2x/@3x rendering.
  • No dedicated small/compact variant — the same asset is reused and simply constrained with max-width at smaller breakpoints (see header.module.scss), instead of shipping a purpose-cropped small logo.
  • Combined lockup (Abaco Systems + AMETEK) increases overall width — verify the spacing between the two marks is intentional design clear-space, not incidental canvas padding.
